About this site

Built by Larry Douglas for CSC102, Introductory Programming, at the University of Advancing Technology. Thirty years as a chief electrician, now chasing faults in JavaScript instead of conduit. The project theme is GrantFlowHQ, my own application for grant discovery and drafting.

All pages use one external stylesheet, this page adds internal CSS for the welcome band, and the box you are reading uses inline CSS.
